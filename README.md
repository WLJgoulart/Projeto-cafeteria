# ☕ Landing Page — Cafeteria

Este projeto é uma landing page moderna desenvolvida para uma **cafeteria**, com visual elegante, vídeo de fundo e modal para exibir informações como endereço e localização.

---

## 🚀 Funcionalidades

* 🎥 **Vídeo de fundo** cobrindo 100% da tela
* 🌑 **Máscara com gradient** para destaque do conteúdo
* 📌 **Menu fixo**, com animação suave em hover
* 📖 **Seção Sobre**, apresentando a cafeteria
* 📍 **Modal de endereço**, aguardando integração da lógica JavaScript
* 📱 **Design responsivo** (em construção, se desejar)

---

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript** (estrutura para abrir o modal será implementada)
* Fonte: *Roboto* (Google Fonts)
